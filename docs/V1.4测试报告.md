# V1.4.0 测试报告

Windows 11 build 26300，Python 3.13.7。所有清理验证使用独立模拟目录。

| 检查 | 结果 |
|---|---|
| 完整 pytest | 72 项通过，39.73 秒。包含既有扫描、监控、搜索、元数据、备份恢复、删除和回收站协议测试 |
| 全局清单 | 201 个重复组，单组 202 个成员，建议覆盖界面未加载的组与成员。401 个勾选项合计 1,604 B |
| 清单交互 | 跨页保留勾选，手动更换保留项及取消个别文件，清空选择。验证按钮到后台生成、预览、确认、执行的完整流程，以及索引无变化时保留清单、有变化时要求重检 |
| 执行安全 | 模拟目标或保留项变化、部分失败、取消、回收站不可用、预览排除项。未选文件与保留项完好 |
| Windows 11 原生界面自检 | 启动、搜索、标注、导出、恢复、目录、监控与重复文件页通过 |
| Windows 11 原生回收站 | 显式运行合成探针，通过真实 Shell 回执确认指定模拟副本入回收站，保留项完好，索引与记录同步 |

布局在本机 Windows 原生 Qt 上以 1366×768 和 1920×1080 对应 100%、125%、150%、200% 的**等效窗口尺寸**检查三页及确认窗口。最小检查区域为 665×346 逻辑像素。重复页内容可滚动，底部预览操作保留。检查了紧凑确认窗口及长路径提示，横向表格通过滚动与悬停查看完整字段。缩放检查采用窗口尺寸模拟，未逐档调整 Windows 系统缩放。公开预览只显示虚构账号和示例文件。

50,000 条模拟索引在 Intel Core Ultra 5 125H、31.6 GiB 内存上实测，SQLite 查询各重复 7 次。首页中位 16.81 ms，中文备注筛选 33.94 ms，按大小排序的末页 51.02 ms，每页均返回 200 条。既有 50,000 条 Qt 列表回归也通过。

复现命令为 `python -m pytest -q`。原生界面自检需指定全新 `WFM_DATA_DIR`，执行 `python run.py --self-test`。实际回收探针需显式运行 `python -m tools.recycle_probe --run-native`，仅创建并处理项目临时目录下的模拟副本。

Windows 10 实机兼容性待验证。本轮交付源码与文档。
