在新的空 WFM_DATA_DIR 中运行 `python run.py --self-test`，使用 Windows 原生 Qt 平台和虚构文件验证启动、搜索、备注标签收藏保存、导出、源文件内容不变、备份恢复以及正常退出，退出码 0。公开截图只包含虚构账号和示例文件，未上传运行时数据库或个人目录信息。

## 50,000 条索引性能

硬件：Intel Core Ultra 5 125H，18 个逻辑处理器，31.6 GiB RAM。50,000 条虚构记录批量插入约 0.88 秒，每项查询重复 7 次，每批返回 200 条。

| 查询 | 中位数 | 最大值 |
|---|---:|---:|
| 首批结果 | 18.037 ms | 22.606 ms |
| 中文备注搜索 | 33.915 ms | 35.014 ms |
| 精确标签筛选 | 23.875 ms | 24.943 ms |
| 按大小排序首批 | 17.646 ms | 19.469 ms |
| 末页（偏移 49,800） | 41.072 ms | 55.635 ms |

复现：`python -m tools.benchmark`。详细结果见 [性能测试.json](性能测试.json)。耗时包含查询和 Python 行转换，不等同于所有硬件上的端到端响应。

## 已知限制

- Windows 10 和独立无 Python 环境尚未完成本轮验收；按最新要求，本轮不进行正式 EXE 打包。此前开发探索产生的本地构建不作为 V1.1 发行物。
- 大规模外部文件变动期间，偏移分页可能出现结果变化，手动刷新后重新查询。
- 单账号索引提交和备份恢复期间，数据库操作可能短暂等待；恢复需等待扫描/导出结束。
- 文件移动或重命名不自动继承旧路径备注，不猜测匹配不同文件。
- 不解密微信数据库或加密附件；外部程序行为取决于本机安装的软件。
- 未人工复现断电场景。真实权限拒绝会保留旧存在状态并报告访问异常。
