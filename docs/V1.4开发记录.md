# V1.4 开发记录

基线为 V1.3 main `8456a4eecd0a696839ab9b254481a61df22d51d0`。主窗口使用 Qt 堆叠页面，微信目录与查找文件共享分页表格和详情组件，重复文件页持有独立的浏览与勾选状态。样式集中到 `app/ui/styles.py`。目录和搜索切换会保留未保存编辑提示。

清理建议在后台按有效哈希和文件大小从 SQLite 流式读取分组，选项以路径为键，组和成员分页只负责呈现。候选经过 V1.3 附件位置、文件属性及卷可用性检查。只有具备可验证保留项的组才生成建议，保留项优先使用本次手动指定项，其次使用收藏或有备注项，再按路径排序。无法验证的文件保留原位并显示原因。手动选择的整组若没有可验证的未选文件，预览会禁止该组操作。

预览以虚拟表格呈现清单，包含原路径、保留路径、账号与预检查，支持逐项取消。若需要更换保留项，可以返回重复文件页调整。执行复用现有计划和回收站接口，在处理每个目标时锁定并检查保留项，重新计算两者内容哈希。文件变化、占用、无效回执和回收站不可用按原有安全边界处理。回收站接收容量与实际释放空间分别表述。

数据库继续使用 schema 5，账号、收藏、备注、标签、目录别名、原始索引与删除日志沿用 V1.3 的存储格式。当前选择和保留项是临时清单，检测结果失效后需重新生成。
