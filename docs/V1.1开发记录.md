## 模块

```text
app/
├── main.py              # 启动，兼容导出 Window / Worker / FilesModel
├── core.py              # Store 兼容入口与账号、别名接口
├── paths.py             # 路径、分类与格式辅助
├── database.py          # 有界连接、schema 迁移、备份恢复
├── scanner.py           # 只读扫描、进度节流和取消
├── search.py            # 过滤、排序、分页、子目录查询
├── annotations.py       # 备注、标签、收藏
├── file_service.py      # 复制、校验、导出
├── selftest.py          # 指定空数据目录中的模拟自检
├── version.py           # 1.1.0 统一版本号
└── ui/
    ├── window.py        # 主窗口协调
    ├── file_model.py    # 分批加载的表格模型
    ├── dialogs.py       # 标签管理和日历筛选
    └── preview.py       # 后台图像解码
```

## 数据升级

使用 SQLite PRAGMA user_version：原始 V1.0 为 0，版本 1 标记兼容结构，版本 2 增加目录父路径及查询索引，版本 3 增加标签目录。迁移不重建文件表或清空备注。

恢复时先校验备份，在一致快照中迁移，自动备份当前数据，再通过 SQLite backup API 写回数据库，避免手动覆盖数据库或删除 WAL。GUI 恢复前要求等待扫描和导出结束。
